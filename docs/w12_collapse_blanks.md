# W12：左栏默认折叠空白会话

日期：2026-11-04

## 两个勾选

左栏顶部现在有两个独立勾选：

| 勾选 | 默认 | 作用 |
| --- | --- | --- |
| 折叠批量会话 | 勾选 | 隐藏 `isChild` 为真的子会话（原有逻辑） |
| 折叠空白会话 | 勾选 | 把同一工作区内 `blank === true` 的会话收成一行「空白会话 × N」 |

两者互不依赖：

- 都勾选：子会话与空白会话都折叠；
- 取消「折叠批量会话」：子会话恢复逐个列出，空白会话仍按「折叠空白会话」处理；
- 取消「折叠空白会话」：空白会话恢复逐个列出，子会话仍按原逻辑处理。

## 空白判定

只认宿主会话行里的 `blank === true`。面板不通过日志大小、消息数或目录名猜空白，避免把有内容但标题为空的会话误折叠。

## 折叠后的样子

同一工作区内有 N 个空白会话、且处于折叠状态时，不逐个渲染这些行，只在组内追加一行：

```
空白会话 × N（点击展开）
```

点击这一行，在**同一个工作区内**展开成逐个空白会话条目，行尾变为「点击收起」；再点一次恢复汇总。展开状态只保存在面板组件的 React state 里，不写文件、不跨会话保存。

展开后的空白条目仍显示「空白会话 · 短ID」，并带小字「新会话，尚未开始对话」，可以正常点击「打开」。工作区标题括号里的数字按当前实际显示的行数计算，折叠时包含那一行汇总。

## 不受影响的部分

- **创建向导第 1、2 步**完全不看这两个勾选：始终列出全部可选项，包括子会话和空白会话，并保留「空白会话 · 短ID」与说明小字；
- 打开会话、整体卡片、解散逻辑、成员显示都不变；
- 折叠只影响左栏会话列表的渲染，不改变底层数据，也不删除任何会话文件。
