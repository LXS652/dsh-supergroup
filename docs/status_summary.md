## 2. 验证方式

```bash
node --check src/plugin2.mjs
node --check client/client.js
node --test tests/*.test.mjs
```

当前发布目录包含 15 个测试文件（旧原生 Team 版本的 `plugin.test.mjs` 未随包发布），共 158 tests，全部通过。

这些测试使用假宿主与临时目录，覆盖：

- 命令解析、成员增删、策略表；
- 投递幂等、结果归集、并发与人类插话；
- 账本持久化、锁、崩溃恢复、启动对账；
- 整体创建/改名/改成员/解散；
- 客户端面板的宿主命令形状（命令通道按 `rawInput` 读取）。

## 3. 没有在本仓库内证明的部分

以下需要真实 DSH 宿主与真实会话才能确认，本仓库的单测不能替代：

- 侧栏图标、面板布局、三步向导、卡片编辑/解散按钮的实际视觉与交互；
- 客户端 bundle 重新加载后的行为；
- 宿主真实事件顺序、历史分页边界、`sessionController` 注册时机；
- 真实成员完成业务动作后的外部副作用。

这些应在部署后按 [使用手册](usage_manual.md) 的验收点人工检查。

## 4. 已知边界

- 对账没有后台轮询，只在启动、`ms2_status`、`/ms2 panel` 三个时机发生。
- 插件不提供进程、目录、网络或 `cwd` 隔离；成员共享宿主环境。
- 账本保证状态可恢复，但不保证外部副作用 exactly-once。
- 不支持主会话转移；lead 在创建时确定。
- 成员最多 8 个；只有 lead 能编辑或解散整体。
- 旧版 `registry.json` 迁移只在 `groups.json` 不存在时发生；迁移后的整体会被标记，重启后不再重复迁移。
